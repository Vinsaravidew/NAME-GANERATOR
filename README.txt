NAME GENERATOR
================

Features
- Unicode-safe font conversion (uses Array.from, so ALVIN/SHAGGY do not break into � characters).
- Many font styles and symbol decorations.
- Copy any generated result.
- Every generated result is automatically published to the shared feed.
- Shared feed polls every 3 seconds, so visitors see names generated by other visitors.
- Data is stored server-side in data.json.

RUN ON A COMPUTER
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run: npm start
4. Open: http://localhost:3000

IMPORTANT FOR PUBLIC INTERNET USE
The shared feed only becomes global when this Node server is deployed online.
For a production deployment, use a host that supports Node.js and persistent storage.
If the host has an ephemeral filesystem, data.json can reset after a restart/redeploy; use a persistent disk or replace data.json with a real database.

The website automatically publishes the exact generated strings (fonts + symbols), not just the plain input name.
